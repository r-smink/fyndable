PageSpeed Insights

Prioriteit: middelhoog | Professional+

Wat doet het en wat levert het jou op?

Meet Core Web Vitals en prestatiescores voor mobiel en desktop via de Google PageSpeed Insights API.

Hoe gebruik je het?

  1. Ga naar Integrations → PageSpeed Insights.
  2. Koppel je Google-account of voer een API-key in.
  3. Open een post en klik Analyze PageSpeed.
  4. Bekijk de scores: LCP, FID/INP, CLS, TTFB en totaal.

Voorbeeld

Je test je homepage en ziet een LCP van 4.2s (slecht). Het advies is om afbeeldingen te comprimeren en lazy-load in te schakelen.

Mogelijke problemen & oplossingen

  • API-key ontbreekt: maak een key aan in Google Cloud Console en voeg deze toe in Integrations.
  • Score verschilt van PageSpeed website: de API kan een andere serverlocatie gebruiken; gebruik de data als trend.
