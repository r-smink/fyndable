Hreflang

Priority: medium | All tiers

What it does and what it gives you

Adds language and region tags so search engines show the correct language variant. Supports WPML, Polylang, TranslatePress and manual mapping.

How to use it

  1. Open the Hreflang accordion in the editor.
  2. Link the translated versions or manually fill in x-default and language codes.
  3. Save.
  4. Test with a hreflang testing tool.

Example

You have a page in Dutch (nl-nl), English (en-gb) and German (de-de). You link the three variants and set x-default to the English version.

Potential issues & solutions

  • Hreflang tags are inconsistent: ensure each language variant refers back to the others.
  • Wrong language codes: use nl-nl, not just nl, unless you have no region-specific variant.
