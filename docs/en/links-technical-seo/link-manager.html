Link Manager

Priority: high | All tiers

What it does and what it gives you

Detects orphan pages, scores internal link opportunities and provides optimized anchor texts. A good internal link structure distributes link value and helps users and crawlers.

How to use it

  1. Go to Link Manager.
  2. Review the Orphan Pages tab.
  3. Click a page to see link suggestions.
  4. Click Add Link or copy the anchor text and URL to a suitable post.

Example

You see that the "About us" page has no internal links. Fyndable suggests linking from your homepage intro with anchor "read more about our team".

Potential issues & solutions

  • Suggestions are irrelevant: adjust the source keyword or refine the target page content.
  • Orphan pages are intentional: some landing pages don't need internal links.
