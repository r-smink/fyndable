404 Monitor

Priority: high | Professional+

What it does and what it gives you

Tracks 404 errors encountered by visitors and crawlers. This prevents lost traffic and poor user experience.

How to use it

  1. Go to Site Audit → 404 Monitor.
  2. Review the list of broken URLs, sorted by hit count.
  3. Click a URL.
  4. Create a 301 redirect to the most relevant page or fix the internal link.

Example

You see that /old-service has been hit 45 times. You create a redirect to /services.

Potential issues & solutions

  • 404s from old campaigns: check the source (referrer) to see if external links point to that URL.
  • Monitor stays empty: ensure the plugin logs errors; sometimes there's a conflict with caching plugins.
