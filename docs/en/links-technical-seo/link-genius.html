Link Genius

Priority: medium | Starter+

What it does and what it gives you

Automatic internal link rules: you determine which words or phrases automatically link to which URL. Great for evergreen links like product categories.

How to use it

  1. Go to Link Genius.
  2. Enable Link Genius.
  3. Add a rule: Keyword(s) → Target URL.
  4. Set the maximum links per page (e.g. 3).
  5. Save.

Example

Rule: "solar panels" → https://yoursite.com/solar-panels/. Everywhere the word appears in content, it's automatically linked, max 3 times per page.

Potential issues & solutions

  • Too many automatic links: lower the maximum or use exact-match instead of partial-match.
  • Links break after removing target page: regularly check if target URLs still exist.
