IndexNow

Priority: medium | All tiers

What it does and what it gives you

Automatically pings search engines (Bing, Yandex) when you change content, so you get indexed faster.

How to use it

  1. Go to Integrations → IndexNow.
  2. Enable IndexNow.
  3. Generate or upload your API key.
  4. Save.
  5. Fyndable now automatically pings on publish and update.

Potential issues & solutions

  • Key file not created: Fyndable tries to auto-create indexnow-key.txt; check if the uploads folder is writable.
  • Bing shows no changes: IndexNow is not a guarantee; it sometimes takes hours to days.
