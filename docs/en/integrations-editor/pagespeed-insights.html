PageSpeed Insights

Priority: medium | Professional+

What it does and what it gives you

Measures Core Web Vitals and performance scores for mobile and desktop via the Google PageSpeed Insights API.

How to use it

  1. Go to Integrations → PageSpeed Insights.
  2. Connect your Google account or enter an API key.
  3. Open a post and click Analyze PageSpeed.
  4. Review the scores: LCP, FID/INP, CLS, TTFB and total.

Example

You test your homepage and see an LCP of 4.2s (poor). The advice is to compress images and enable lazy-load.

Potential issues & solutions

  • API key missing: create a key in Google Cloud Console and add it in Integrations.
  • Score differs from PageSpeed website: the API may use a different server location; use the data as a trend.
