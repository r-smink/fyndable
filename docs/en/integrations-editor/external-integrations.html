External Integrations

Priority: medium | Professional+

What it does and what it gives you

Connects external services like Google Search Console, GA4, Google Ads, PageSpeed Insights, SE Ranking, Ahrefs, IndexNow and the Google Indexing API. This data is used in dashboards and AI analyses.

How to use it

  1. Go to Integrations.
  2. Choose the desired service.
  3. Follow the OAuth flow or enter an API key.
  4. Save the connection.
  5. Test in the corresponding dashboard if data comes in.

Example

You connect Search Console. In Google Data you now see clicks, impressions and CTR per page.

Potential issues & solutions

  • OAuth doesn't allow correct domain: ensure your domain is added in Google Cloud OAuth settings.
  • API quota is limited: see Settings → License for your quota.
