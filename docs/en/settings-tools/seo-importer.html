SEO Importer

Priority: medium | All tiers

What it does and what it gives you

Imports meta data (SEO titles, descriptions, focus keywords) from Yoast SEO, Rank Math or All in One SEO. Useful when migrating to Fyndable.

How to use it

  1. Go to Settings → SEO Importer.
  2. Choose the source plugin.
  3. Click Import.
  4. Wait for the process to complete.
  5. Check a few posts to verify the data was imported correctly.

Example

You migrate from Yoast to Fyndable. After import you see all SEO titles and descriptions have been transferred. You can now deactivate Yoast.

Potential issues & solutions

  • Import stops halfway: increase PHP max_execution_time and try again.
  • Some posts missing data: check if the source plugin still has the data; sometimes fields are empty in the source.
  • Duplicate data after import: Fyndable overwrites empty fields; already filled fields are preserved unless you check "Overwrite".
