Role-based Permissions

Priority: medium | Professional+

What it does and what it gives you

Determines which WordPress roles have access to which Fyndable features. Useful for teams with editors, SEO specialists and administrators.

How to use it

  1. Go to Settings → Role Permissions.
  2. Select a role (e.g. Editor).
  3. Check which menus and features this role can see.
  4. Save.

Example

You give Editors access to Content Calendar, Keywords and AI Tools, but not to Settings and Integrations. Only Administrators have full access.

Potential issues & solutions

  • Roles still see hidden menus: reload the page or clear the cache.
  • Custom roles missing: Fyndable supports standard WordPress roles; custom roles can be added manually via code.
