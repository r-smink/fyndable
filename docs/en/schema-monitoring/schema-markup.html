Schema Markup Manager

Priority: high | Professional+

What it does and what it gives you

Adds structured data (JSON-LD) to your pages. Search engines use this for rich snippets: stars, FAQ accordions, carousels and more.

How to use it

  1. Open the Schema accordion in the editor.
  2. Click Add Schema.
  3. Choose a type, e.g. Article, Product, LocalBusiness, Review.
  4. Fill in the required fields.
  5. Click Validate to test.
  6. Save the post.

Example

For a blog post you choose Article, fill in author, publish date and publisher. Google can show this in search results with date and author.

Potential issues & solutions

  • Error in Google Rich Results Test: check if all required fields are correctly filled.
  • Duplicate schema: disable conflicting schema plugins (Yoast, Rank Math) if you want Fyndable as the leading schema.
