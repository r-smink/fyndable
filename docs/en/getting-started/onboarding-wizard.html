Onboarding Wizard

Priority: high | All tiers

What it does and what it gives you

The wizard helps you set up the basics of Fyndable correctly in a few minutes, so you don't have to wade through all settings manually.

How to use it

  1. After activation the wizard appears automatically. Click Start.
  2. Step 1 — License: check if your license is active and recognized.
  3. Step 2 — Basic SEO: fill in title separators, site name, social profiles and default Open Graph image.
  4. Step 3 — Content types: check which post types should have SEO tools active (usually post, page and optionally product).
  5. Step 4 — Google integrations: optionally connect Search Console, GA4 or PageSpeed.
  6. Click Finish; you'll be redirected to the dashboard.

Example

For a blog you select only post and page. For a WooCommerce shop you also add product so product schema and WooCommerce SEO panels are available.

Potential issues & solutions

  • Wizard doesn't start: go to /wp-admin/admin.php?page=ai-seo-onboarding manually.
  • Google connection fails: skip the wizard and connect later via Integrations.
