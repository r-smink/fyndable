Topic Clusters

Priority: high | Professional+

What it does and what it gives you

Generates a pillar-cluster map: one main topic (pillar) with underlying articles (clusters). Helps you build topical authority.

How to use it

  1. Go to Topic Clusters.
  2. Enter a main topic, e.g. "sustainable energy".
  3. Click Generate Cluster.
  4. Review the suggested pillar and clusters.
  5. Create the pillar page first, then the cluster articles, and link them to the pillar.

Example

Pillar: "All about solar panels". Clusters: "solar panel costs", "solar panel permits", "solar panel yield", "solar panel maintenance".

Potential issues & solutions

  • Cluster ideas overlap: combine or split them.
  • Too many clusters: start with 3-5 clusters per pillar.
