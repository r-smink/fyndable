Created Posts

Priority: medium | All tiers

What it does and what it gives you

Central overview of all AI-generated posts, sorted by status: draft, scheduled, published, needs review.

How to use it

  1. Go to Created Posts.
  2. Use filters to quickly find drafts or scheduled posts.
  3. Select one or more posts.
  4. Choose Bulk Publish, Bulk Draft or Regenerate.

Example

You have 10 generated drafts. You select 5, edit them quickly and click Bulk Publish to make them live in one go.

Potential issues & solutions

  • Post missing images: manually add a featured image or use AI Image Generator.
  • Bulk action fails: reload the page and check if you have sufficient permissions.
