AI Image Generator

Priority: low-medium | All tiers

What it does and what it gives you

Generates featured images, Open Graph images or illustrations based on a prompt.

How to use it

  1. Open the AI Image accordion in the editor.
  2. Choose the image type.
  3. Enter a prompt, e.g. "minimalist flat design of an electric bike, mint green background".
  4. Click Generate Image.
  5. Select a result and set it as featured image.

Example

For an article about "workplace happiness" you request an image of "a cheerful team working in an office, natural light". You use it as featured image.

Potential issues & solutions

  • Images don't generate: check if the image API (OpenAI/DALL-E or Stability) is configured in the dashboard.
  • Brand doesn't match: add brand terms in the prompt or edit the image afterward.
